# 平面图 SVG 交付约定

Illustrator 导出可帮助保留原图的矢量线条，并清理标题、留白和静态点位标注。先处理水冶一楼作为样板即可，其余图纸按样板整理。

## 交付文件

放入 `pmt/svg/`，各区域 / 楼层独立文件：

| 源文件 | 建议文件名 |
| --- | --- |
| C19采区.pdf | c19.svg |
| C35采区.pdf | c35.svg |
| C3采区(1).pdf | c3.svg |
| 集中过滤厂房.pdf | filter.svg |
| 水冶一楼.pdf | hydromet-f1.svg |
| 水冶二楼.pdf | hydromet-f2.svg |
| 水冶三楼.pdf | hydromet-f3.svg |
| 水冶四楼.pdf | hydromet-f4.svg |

`水冶一层.pdf` 保留作资产编号核对，不需要重复转换；`环境监测点位分布.pdf` 暂不需要转换。

## 图层与画板

- 保留墙体、门、楼梯、设备轮廓及必要的房间名称，放在 `base` 图层。
- 将监测点圆圈、γ 编号、氡编号和资产号放在独立的 `device-reference` 图层，保留原位置。无需按最新配置手工改编号：原图与实际设备的映射由前端台账处理。
- 裁掉大块留白、图签和外框，画板适配有效平面图，保留少量边距；保持原始比例和方向。各楼层无需强行统一宽高。
- 不需要美化配色或调整设备安装位置。文字若存在字体缺失，应先检查与 PDF 的一致性，再处理导出。

建议交付两个版本：

1. `hydromet-f1.svg`：只显示底图，供前端使用。
2. `hydromet-f1-reference.svg`：显示底图和原始点位标注，用于录入安装坐标。

两个版本必须共用完全相同的画板、尺寸及 `viewBox`，导出参考版本时不要重新适配画板。也可另附保留分层的 `.ai` 原稿。若导出工具没有保留图层命名，两个版本本身仍足够完成接入。

## 导出要求

- 导出实际矢量 SVG，保留 `viewBox`，避免仅把整张 PDF 栅格化后嵌入 SVG。
- 静态中文房间名称可转轮廓，以减少浏览器字体差异；设备名、读数、单位由前端生成，无需在底图中制作。
- 若含图片，将图片嵌入文件，避免依赖本机路径；不需要保留 Illustrator 编辑数据。
- 背景可以透明，保留清楚的墙体线条即可。原图红色线条中可能包含墙、门或设施，不能按颜色整批删除；只分离监测点及对应标注。
- 导出后检查墙体、门和文字未丢失或被裁切。无需手工编辑 XML 或录入坐标；坐标录入、文件优化和前端适配由代码侧完成。

最终设备绑定以确认的最新配置为准。特别是 C35 `.13` 与水冶 `.16` 的氡节点，原图和最新现场说明存在互换差异，不能仅凭 SVG 标签决定读数归属。
