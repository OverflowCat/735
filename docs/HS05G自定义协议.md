## 集线器与节点 RS485 接口通信协议

命令均为 **Hex 格式数据**。

### 命令格式

```
0xA5, 0x5A, DeviceID, Cmd0~2, Par1, Par2   （共 8 字节）
```

| 字段 | 说明 |
|------|------|
| 帧头 | `0xA5`, `0x5A`（固定） |
| DeviceID | 设备地址 |
| Cmd0, Cmd1, Cmd2 | 命令代码 |
| Par1, Par2 | 参数代码 |

### 命令列表

#### Cmd0=0x01, Cmd1=0x01, Cmd2=0x01 — 设置周期

- **用途**：设置测量周期
- **应答**：广播命令，无返回信息

> 其它 Cmd3 等忽略。

#### Cmd0=0x02, Cmd1=0x02, Cmd2=0x02 — OLED 闪烁显示

- **用途**：设置 OLED 显示器闪烁显示，增加 OLED 发光使用寿命
- **应答**：广播命令，无返回信息

#### Cmd0=0x03, Cmd1=0x03, Cmd2=0x03 — 读取当前测量数据

- **用途**：读取节点当前测量数据
- **应答**：

```
0xA5, 0x5A, DeviceID, [8 字节测量数据]
```

#### Cmd0=0x04, Cmd1=0x04, Cmd2=0x04 — 软件复位

- **用途**：软件复位节点，每个节点重新启动
- **应答**：广播命令，无返回信息

### 8 字节测量数据结构

| 字节位置 | 字节数 | 说明 |
|----------|--------|------|
| 1–2 | 2 | 氡浓度（高字节 + 低字节） |
| 3–4 | 2 | 计数值（高字节 + 低字节） |
| 5 | 1 | 温度（无小数点，原始值） |
| 6 | 1 | 湿度（无小数点，原始值） |
| 7 | 1 | 周期 |
| 8 | 1 | 节点号 |

## 集线器与网络 RJ45 接口通信协议

命令均为 **Hex 格式数据**。

### 命令格式

```
0xA5 + 0x5A + Cmd + Par1~Par6 + 备用1字节 + Cmd1 + Cmd2   （共 12 字节）
```

| 字段 | 说明 |
|------|------|
| 帧头 | `0xA5`, `0x5A`（固定） |
| Cmd | 命令代码 |
| Par1~Par6 | 参数代码 |
| 备用 | 1 字节 |
| Cmd1, Cmd2 | 命令校验/确认 |

### 返回格式

- 数据包（Cmd=0x01、Cmd=0x09）：**130 字节**
- 其它命令应答：**8 字节**

### 命令列表

#### Cmd=0x01 — 读取当前数据

**接收格式：**

```
0xA5 + 0x5A + 0x01 + [任意 7 字节] + 0x01 + 0x01   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + [128 字节当前测量数据包]   （共 130 字节）
```

#### Cmd=0x02 — 设置周期（广播命令）

**接收格式：**

```
0xA5 + 0x5A + 0x02 + 周期 + [任意 6 字节] + 0x02 + 0x02   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x02 + 'O' + 'K' + 0x00 + [任意 2 字节]
```

#### Cmd=0x03 — 设置集线器号

**接收格式：**

```
0xA5 + 0x5A + 0x03 + 集线器号 + [任意 6 字节] + 0x03 + 0x03   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x03 + 'O' + 'K' + 0x00 + [任意 2 字节]
```

#### Cmd=0x04 — 设置管理的测氡仪数量

**接收格式：**

```
0xA5 + 0x5A + 0x04 + 测氡仪数量 + [任意 6 字节] + 0x04 + 0x04   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x04 + 'O' + 'K' + 0x00 + [任意 2 字节]
```

#### Cmd=0x05 — 擦除数据

**接收格式：**

```
0xA5 + 0x5A + 0x05 + [任意 7 字节] + 0x05 + 0x05   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x05 + 'O' + 'K' + 0x00 + [任意 2 字节]
```

#### Cmd=0x06 — 设置 RTC（实时时钟）

**接收格式：**

```
0xA5 + 0x5A + 0x06 + [RTC 6字节：年月日时分秒] + [任意 1 字节] + 0x06 + 0x06   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x02 + 'O' + 'K' + 0x00 + [任意 2 字节]
```

#### Cmd=0x07 — 设置 OLED 显示参数（广播命令）

**接收格式：**

```
0xA5 + 0x5A + 0x07 + 控制字 + [任意 6 字节] + 0x07 + 0x07   （共 12 字节）
```

| 控制字 | 含义 |
|--------|------|
| `0xAA` | 闪烁显示 |
| 其它值 | 不闪烁显示 |

#### Cmd=0x08 — 读取文件量

**接收格式：**

```
0xA5 + 0x5A + 0x08 + [任意 7 字节] + 0x08 + 0x08   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x08 + 'O' + 'K' + 0x00 + 文件号高 + 文件号低
```

#### Cmd=0x09 — 读取指定文件号数据

**接收格式：**

```
0xA5 + 0x5A + 0x09 + FileH + FileL + [任意 5 字节] + 0x09 + 0x09   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + [128 字节数据包]
```

#### Cmd=0x0A — 软件复位节点（广播命令）

**接收格式：**

```
0xA5 + 0x5A + 0x0A + [任意 7 字节] + 0x0A + 0x0A   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x0A + 'O' + 'K' + 0x00 + [任意 2 字节]
```

#### Cmd=0x0B — 读取参数命令

**接收格式：**

```
0xA5 + 0x5A + 0x0B + [任意 7 字节] + 0x0B + 0x0B   （共 12 字节）
```

**返回：**

```
0xA5 + 0x5A + 0x0A + 'O' + 'K' + 0x00 + 节点数 + 文件号高 + 文件号低 + 年 + 月 + 日 + 时 + 分
```

## 128 字节数据包结构

### 整体布局

| 偏移 | 长度 | 说明 |
|------|------|------|
| 0–119 | 120 字节 | 节点 1 ~ 节点 15，每节点 **8 字节** |
| 120–121 | 2 字节 | 气压（高字节 + 低字节） |
| 122–126 | 5 字节 | 年、月、日、时、分 |
| 127 | 1 字节 | 周期 |

### 节点 N 数据（8 字节）

| 字节 | 字节数 | 说明 |
|------|--------|------|
| 1 | 1 | 氡浓度高字节 |
| 2 | 1 | 氡浓度低字节 |
| 3 | 1 | 气压高字节 |
| 4 | 1 | 气压低字节 |
| 5 | 1 | 温度 |
| 6 | 1 | 湿度 |
| 7 | 1 | 周期 |
| 8 | 1 | 节点号 |
